# Project 1 - Data Science Job Market & Salary Dashboard

## Project Overview

An interactive Excel dashboard designed to explore job market trends and salary information across various data-related occupations worldwide.

Using approximately 140,000 job postings, the dashboard allows users to analyse median salaries based on job title, country, and employment type. Users can interact with dropdown filters to dynamically explore salary comparisons and gain insights into the global data science job market.

## Key Features

- **Interactive Filters:** Dropdown selections for job title, country, and employment type.
- **Salary Analysis:** Calculates median salaries across different data-related occupations.
- **Job Title Comparison:** Visualizes salary differences between various job roles.
- **Employment Type Analysis:** Compares median salaries across full-time, part-time, contractor, and internship positions.
- **Dynamic Dashboard:** Automatically updates calculations and visualizations based on user selections.
- **Recruitment Platform Analysis:** Examines job posting counts across different recruitment platforms.

## Technical Skills & Tools

- **Microsoft Excel:** Dashboard development and data analysis.
- **Excel Tables:** Structured data management and referencing.
- **Excel Formulas:** IF, COUNTIFS, MEDIAN, SEARCH, SUBSTITUTE.
- **Dynamic Array Functions:** UNIQUE, SORT, FILTER.
- **Lookup Functions:** XLOOKUP.
- **Data Validation:** Interactive dropdown lists.
- **Data Visualization:** Charts, KPI displays, and dashboard design.

## Project Objectives

- Analyse salary differences across data-related occupations.
- Explore how location and employment type influence salary levels.
- Develop an interactive dashboard to make job market information easier to explore.
- Apply advanced Excel functions to perform conditional calculations and present analytical results.
