# Excel_Projects
The following Excel projects were completed as part of my Excel course. They demonstrate my practical skills and understanding of data analysis, data visualization, and data transformation using Excel tools such as Power Query, Power Pivot, Pivot Tables, and various Excel formulas and functions.   

## Project 1 - Job Dashboard   
An interactive dashboard built using a global Data Science job market dataset. The dashboard provides insights into median salaries across different job roles and countries, allowing users to explore and compare salary trends through interactive visualizations.

**Skills & Tools Used:**
- 📉 Charts & Data Visualization
- 🧮 Excel Formulas & Functions
- ❎ Data Validation
- 📊 Interactive Dashboard Design

## Porject 2 - Data Analysis
This project builds on the same dataset used in Project 1, focusing on exploring relationships between job skills and salaries. The analysis aims to identify correlations between in-demand technical skills and compensation, as well as highlight the most sought-after skills among data professionals.

**Skills & Tools Used:**
- 📊 Pivot Tables
- 📈 Pivot Charts
- 🧮 DAX (Data Analysis Expressions)
- 🔍 Power Query
- 💪 Power Pivot
