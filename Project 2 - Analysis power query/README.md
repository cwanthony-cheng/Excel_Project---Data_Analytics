# Project 2 - Data Job Market: Salary & Skills Analysis

## Project Overview

An Excel-based data analysis project exploring salary trends and technical skill requirements across various data-related occupations.

The project uses job market data to investigate the relationship between salary levels, the number of skills required per job, and the demand for specific technical skills.

Using Power Query, Power Pivot, the Excel Data Model, and PivotTables, I developed analytical reports and visualizations to identify salary differences and skill requirements across different occupations and geographic markets.

## Key Analysis

### 1. Salary vs. Skills Analysis
- Examined the relationship between median salaries and the average number of skills required per job.
- Created a scatter plot with a trendline to visualize the relationship.
- Compared salary and skill requirements across different job titles.

### 2. US vs. Non-US Salary Comparison
- Compared median salaries across data-related occupations.
- Analysed salary differences between US and non-US job markets.
- Identified variations in compensation across different job roles.

### 3. Job-Specific Skills Analysis
- Analysed the most frequently required technical skills for different job titles.
- Used interactive slicers to filter skill requirements by occupation.
- Compared the likelihood of specific skills appearing in job postings.

### 4. Skill & Salary Analysis
- Compared median salaries associated with different technical skills.
- Examined skill demand alongside salary information.
- Identified commonly requested technical skills and their associated salary levels.

## Technical Skills & Tools

- **Microsoft Excel:** Data analysis and reporting.
- **Power Query:** Data query management and preparation.
- **Power Pivot:** Data Model and analytical reporting.
- **Excel Data Model:** Working with multiple datasets and analytical measures.
- **PivotTables:** Data summarization and comparative analysis.
- **PivotCharts:** Visual representation of analytical findings.
- **Slicers:** Interactive filtering and data exploration.
- **Data Visualization:** Scatter plots, trendlines, and bar charts.

## Key Takeaways

- Explored the relationship between salary levels and the number of skills required per job.
- Identified differences in salary levels between US and non-US job markets.
- Investigated the most frequently requested technical skills across different occupations.
- Compared skill demand with median salary levels to better understand the data job market.
